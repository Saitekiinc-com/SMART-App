# SMART Team Goals

チームが自律的に課題を発見し、SMARTの指針に基づいた具体的かつ測定可能なゴールを設定・達成することで、継続的な改善と成長を実現するプラットフォーム。

## プロジェクト概要

SMART Team Goalsは、エンジニアリングチームリーダーとメンバーが協力して、効果的な目標設定と課題解決を行うためのWebアプリケーションです。

### 主な機能

- **SMARTゴール作成ウィザード**: 具体的で測定可能な目標を段階的に設定
- **投票機能**: チーム全員で優先順位を決定
- **進捗管理**: リアルタイムでゴールの進捗を可視化
- **通知機能**: 重要なイベントをチームに通知
- **権限管理**: リーダーとメンバーの役割を明確化
