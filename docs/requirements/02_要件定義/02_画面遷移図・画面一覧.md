# 02_画面遷移図・画面一覧

## 1. 画面一覧

1. **ログイン / サインアップ**: 認証画面
2. **招待受諾画面**: 招待リンクからのランディング
3. **チーム選択**: 所属チームの選択
4. **チームダッシュボード**: ゴール一覧、サマリー表示
5. **SMARTゴール作成ウィザード**: ゴール作成フォーム
6. **ゴール詳細**: 詳細情報、投票、アプローチ管理
7. **ゴール編集画面**: 既存ゴールの編集
8. **通知一覧モーダル**: 通知の確認
9. **チーム設定画面**: チーム情報、メンバー管理
10. **招待リンク生成モーダル**: 招待URLの発行

## 2. 画面遷移図 (Mermaid)

```mermaid
graph TD
    Login[ログイン画面] --> TeamSelect[チーム選択]
    InviteLink[招待リンク] --> InviteAccept[招待受諾画面]
    InviteAccept --> Login
    InviteAccept --> TeamSelect

    TeamSelect --> Dashboard[ダッシュボード]

    Dashboard -- 新規作成 --> Wizard[SMARTウィザード]
    Wizard -- 保存 --> Dashboard
    Wizard -- キャンセル --> Dashboard

    Dashboard -- ゴールクリック --> Detail[ゴール詳細]
    Detail -- 編集 --> EditGoal[ゴール編集]
    EditGoal -- 保存 --> Detail
    EditGoal -- キャンセル --> Detail
    Detail -- 戻る --> Dashboard

    Dashboard -- 通知アイコン --> Notification[通知一覧モーダル]
    Notification -- 通知クリック --> Detail
    Notification -- 閉じる --> Dashboard

    Dashboard -- チーム切替 --> TeamSelect
    Dashboard -- 設定 --> TeamSettings[チーム設定]
    TeamSettings -- 招待 --> InviteModal[招待リンク生成モーダル]
    InviteModal -- 閉じる --> TeamSettings
    TeamSettings -- 戻る --> Dashboard
```
