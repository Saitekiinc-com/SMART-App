# 07_ユーザー要求定義書

## 1. プロダクトビジョン

チームが自律的に課題を発見し、SMARTの指針に基づいた具体的かつ測定可能なゴールを設定・達成することで、継続的な改善と成長を実現するプラットフォームを提供する。

## 2. 背景と目的

エンジニアリングチームにおいて、課題解決が属人化したり、漠然とした目標設定により改善が進まないという問題がある。

本プロダクトは、SMARTのフレームワークを導入することで、チーム全員が納得感を持って課題解決に取り組める環境を作ることを目的とする。

## 3. ペルソナとターゲット

### ターゲットユーザー：エンジニアリーダー（プレイングマネージャー）

- **管轄**: 2チーム（各4名、計8名のメンバー）
- **現状の悩み**:
  - チームの問題を自ら発見し解決する動きが弱い
  - メンバーからの報告が上がってこない、または報告先に迷っている
  - 「解決しなくてもなんとかなっている」という現状維持バイアスがある
- **ニーズ**:
  - チームの課題を可視化したい
  - 課題解決の優先順位をチーム全員で合意形成したい
  - 漠然とした課題をSMARTなゴールに落とし込みたい

### チームメンバー：現場エンジニア

- **現状**: 日々の業務に追われ、課題解決の優先度が低い、または声を上げる場所がないと感じている

## 4. 解決すべき課題

1. **課題の放置**: 重要だが緊急ではない課題（技術的負債、プロセス改善など）が後回しにされる
2. **ゴールの曖昧さ**: 「もっと良くする」「頑張る」といった具体性に欠ける目標設定
3. **オーナーシップの欠如**: 誰がいつまでに何をするかが不明確
4. **アプローチの不明確さ**: ゴールは決まったが、具体的にどう動くかがチーム内で共有されていない
5. **優先順位の不一致**: チームメンバー間で課題の重要度認識にズレがある
6. **進捗の不透明さ**: 取り組んでいる課題の状況がリアルタイムで把握できない

## 5. ソリューション概要

チームごとにSMARTの指針に従ったゴールを設定・管理するWebアプリケーション。

### コアコンセプト

- **ウィザード形式**: SMARTの5要素をウィザード形式で入力することで、質の高いゴール設定をナビゲートする
- **アプローチ共有**: ゴールに対する具体的なアプローチを共有し、チームのアクションを明確にする
- **投票による合意形成**: チームメンバー全員で投票し、優先すべきゴールを民主的に決定する
- **リアルタイム通知**: ゴールの進捗や重要なイベントを通知し、チーム全員の認識を揃える
- **可視化**: チームのゴールと進捗（進行中ステータス含む）を一目で把握できるようにする
