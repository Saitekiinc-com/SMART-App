# 999_用語集

本プロジェクト（Saiteki）で使用する用語の定義です。

## ユーザー・権限

| 用語 | 読み | 定義 |
| --- | --- | --- |
| **ユーザー** | ゆーざー | システムに登録された利用者。チームのリーダー・メンバーのいずれか、または複数チームに所属しうる。 |
| **ロール** | ろーる | チーム内での役割。このシステムでは **Leader（リーダー）** と **Member（メンバー）** の2種類。何ができるかを決める。 |
| **リーダー** | りーだー | チームの管理者。チーム作成・メンバー招待・チーム設定変更などが可能。チーム作成者はそのチームのリーダーとなる。 |
| **メンバー** | めんばー | チームの一般参加者。ゴールの作成・編集（自分のもの）、投票、ステータス変更は可能。招待やチーム設定は不可。 |

## チーム・ゴール

| 用語 | 読み | 定義 |
| --- | --- | --- |
| **チーム** | ちーむ | 複数ユーザーが所属する単位。ゴールはチームに紐づく。リーダーが作成する。 |
| **SMARTゴール** | スマートごーる | 具体的(Specific)、測定可能(Measurable)、達成可能(Achievable)、関連性(Relevant)、期限(Time-bound) の5要素で定義する目標。本システムではアプローチ（手順）も含めて策定する。 |
| **アプローチ** | あぷろーち | ゴールを達成するための具体的な手順・やることリスト。最大10項目。各項目に完了フラグを持ち、進捗を可視化する。 |
| **所有者** | しょゆうしゃ | ゴールを「誰のゴールとして管理するか」を表すユーザー。デフォルトはゴール作成者。通知の宛先などに使う。 |
| **ステータス** | すてーたす | ゴールの進捗状態。**TODO**（未着手）、**IN_PROGRESS**（進行中）、**DONE**（完了）の3種。 |

## 投票・招待・通知

| 用語 | 読み | 定義 |
| --- | --- | --- |
| **投票** | とうひょう | メンバーがゴールの優先度を表すために1ゴール1票で行う操作。投票数でゴールの優先順位を可視化する。 |
| **招待** | しょうたい | リーダーが発行する招待リンク。トークン付きURLで、有効期限7日・1回のみ使用可能。未登録ユーザーもサインアップ後にチームに参加できる。 |
| **通知** | つうち | アプリ内でユーザーに届くメッセージ。新ゴール作成・ステータス変更・期限リマインダー・ゴール完了などのイベントで発火。未読/既読を持つ。 |
