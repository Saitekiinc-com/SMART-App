# 05_テーブル・ファイル定義一覧

GitHubの [システム要件定義書](https://github.com/Saitekiinc-com/SMART-App/blob/main/docs/requirements/system_requirements.md) に基づくデータ項目定義です。

## 1. User (ユーザー)

システム利用者。

| 項目名 | 型 | 必須 | 制約・補足 |
| --- | --- | --- | --- |
| **ユーザーID** (PK) | UUID | 〇 | |
| **名前** | String | 〇 | |
| **メールアドレス** | String | 〇 | Unique |
| **パスワードハッシュ** | String | 〇 | |
| **アイコンURL** | String | - | |
| **role** | Enum | - | leader / member (システム要件定義書 2.6参照) |

## 2. Team (チーム)

プロジェクトチーム。

| 項目名 | 型 | 必須 | 制約・補足 |
| --- | --- | --- | --- |
| **チームID** (PK) | UUID | 〇 | |
| **チーム名** | String | 〇 | 最大50文字 |
| **説明** | String | - | 最大200文字 |
| **作成者ID** (FK) | UUID | 〇 | User参照 |

## 3. TeamMember (チームメンバー)

チームへの所属情報。

| 項目名 | 型 | 必須 | 制約・補足 |
| --- | --- | --- | --- |
| **ID** (PK) | UUID | 〇 | |
| **チームID** (FK) | UUID | 〇 | Team参照 |
| **ユーザーID** (FK) | UUID | 〇 | User参照 |
| **ロール** | Enum | 〇 | Leader / Member |

## 4. SMARTGoal (SMARTゴール)

チームの目標。

| 項目名 | 型 | 必須 | 制約・補足 |
| --- | --- | --- | --- |
| **ゴールID** (PK) | UUID | 〇 | |
| **チームID** (FK) | UUID | 〇 | Team参照 |
| **タイトル** | String | 〇 | 最大100文字 |
| **具体的 (Specific)** | Text | 〇 | 10-500文字 |
| **測定可能 (Measurable)** | Text | 〇 | 最大200文字 |
| **達成可能 (Achievable)** | Boolean | 〇 | |
| **関連性 (Relevant)** | Text | 〇 | 最大200文字 |
| **期限 (Time-bound)** | Date | 〇 | 未来の日付 |
| **アプローチ** | JSON/List | 〇 | 最大10項目。各項目に完了フラグを持つ |
| **所有者ID** (FK) | UUID | 〇 | TeamMember参照。デフォルトは作成者 |
| **ステータス** | Enum | 〇 | `TODO`, `IN_PROGRESS`, `DONE` (初期値: TODO) |
| **投票数** | Integer | - | 0以上 |

## 5. Vote (投票)

ゴールへの優先度投票。

| 項目名 | 型 | 必須 | 制約・補足 |
| --- | --- | --- | --- |
| **投票ID** (PK) | UUID | 〇 | |
| **ゴールID** (FK) | UUID | 〇 | SMARTGoal参照 |
| **ユーザーID** (FK) | UUID | 〇 | User参照 |
| **投票日時** | Timestamp | 〇 | |

**制約**:

- 1ユーザーは1ゴールに1票まで
- Unique (ゴールID, ユーザーID)

## 6. Invitation (招待)

チームへの招待リンク管理。

| 項目名 | 型 | 必須 | 制約・補足 |
| --- | --- | --- | --- |
| **招待ID** (PK) | UUID | 〇 | |
| **トークン** | String | 〇 | UUID形式, Unique |
| **チームID** (FK) | UUID | 〇 | Team参照 |
| **招待者ID** (FK) | UUID | 〇 | User参照 (リーダー) |
| **有効期限** | Timestamp | 〇 | 作成日時+7日 |
| **使用済みフラグ** | Boolean | 〇 | 初期値: false |
| **使用日時** | Timestamp | - | |

## 7. Notification (通知)

ユーザーへの通知。

| 項目名 | 型 | 必須 | 制約・補足 |
| --- | --- | --- | --- |
| **通知ID** (PK) | UUID | 〇 | |
| **ユーザーID** (FK) | UUID | 〇 | User参照 |
| **種別** | Enum | 〇 | `GOAL_CREATED`, `STATUS_CHANGED`, `DEADLINE_REMINDER`, `GOAL_COMPLETED` |
| **メッセージ** | String | 〇 | 最大500文字 |
| **関連ゴールID** (FK) | UUID | - | SMARTGoal参照 |
| **既読フラグ** | Boolean | 〇 | 初期値: false |
| **作成日時** | Timestamp | 〇 | |
