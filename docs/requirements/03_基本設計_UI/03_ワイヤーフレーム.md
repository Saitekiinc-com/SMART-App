## ワイヤーフレーム作成フロー

- **人** → AIに各画面毎のワイヤーフレーム用のHTMLコードをインラインCSSで作る指示を出す。
- **AI** → 各画面のHTMLをNotionとローカルに作成。
- **人** → CursorでLive Previewの拡張機能を使い、スクリーンショットを直接設計書に張り付ける。

※ mermaid.js はコンポーネントの配置などには適さないため、HTMLでワイヤーフレームを作成。
