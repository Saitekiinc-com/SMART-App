# ディレクトリ構成

設計書（07_コンポーネント設計、08_純粋関数の設計、09_カスタムフック設計、01_データベース詳細設計書）に基づくアプリケーションのディレクトリ構成です。

## ルート

```
Smart_App/
├── app/                 # Next.js App Router（ページ・API・レイアウト）
├── components/          # React コンポーネント（ui / auth / dashboard / goal / team / notifications / invite）
├── lib/                  # 純粋関数（validation / format / api）
├── hooks/                # カスタムフック
├── prisma/               # スキーマ・マイグレーション
└── docs/requirements/    # 要件定義・基本設計・詳細設計ドキュメント
```

## app/

- **(auth)/login** … S-01 ログイン/サインアップ
- **(app)/** … 認証後エリア（layout でヘッダー・認証ガード）
  - **dashboard/[teamId]** … S-04 チームダッシュボード
  - **goals/[goalId]** … S-06 ゴール詳細
  - **goals/[goalId]/edit** … S-07 ゴール編集
  - **settings/[teamId]** … S-09 チーム設定
- **invite/[token]** … S-02 招待受諾
- **api/** … API Routes（auth, users, invites, teams, goals, approaches, notifications）

## components/

- **ui/** … 共通UI（Button, Input, StatusBadge, VoteUI, FAB, AppHeader 等）
- **auth/** … AuthForm
- **dashboard/** … GoalList, GoalCard
- **goal/** … WizardFrame, GoalDetailPanel
- **team/** … TeamSelectList, TeamSettingsContent
- **notifications/** … NotificationListModal
- **invite/** … InviteLinkModal, InviteAcceptCard

## lib/

- **validation/** … auth, goal, team
- **format/** … status, date
- **api/** … goal, team（API ボディ組み立て）
