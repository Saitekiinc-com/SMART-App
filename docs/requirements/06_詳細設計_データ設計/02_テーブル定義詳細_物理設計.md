# 02_テーブル定義詳細(物理設計)

## 目的

基本設計のテーブル定義を詳細化し、物理的なデータベース設計を記載する。
実装担当者が「迷わずにSQLを書き、テーブルを作成できる」レベルを目指す。

---

## 1. users（ユーザー）

システム利用者の認証・プロフィール情報を管理する。

### カラム定義

| 論理名 | 物理名 | PostgreSQL型 | NULL | デフォルト値 | 補足 |
|--------|--------|--------------|------|--------------|------|
| ユーザーID | id | UUID | NOT NULL | - | PRIMARY KEY |
| 名前 | name | VARCHAR(100) | NOT NULL | - | - |
| メールアドレス | email | VARCHAR(255) | NOT NULL | - | UNIQUE |
| パスワードハッシュ | password_hash | VARCHAR(255) | NOT NULL | - | ハッシュ化されたパスワード |
| アイコンURL | icon_url | VARCHAR(500) | NULL | - | 任意 |
| 作成日時 | created_at | TIMESTAMP | NOT NULL | CURRENT_TIMESTAMP | - |
| 更新日時 | updated_at | TIMESTAMP | NULL | - | - |

### 主キー・外部キー定義

| 種別 | カラム名 | 制約名 | 参照先 | 補足 |
|------|----------|--------|--------|------|
| PRIMARY KEY | id | users_pkey | - | - |

### 制約定義

| 制約種別 | カラム名 | 制約名 | 条件・値 |
|----------|----------|--------|----------|
| UNIQUE | email | users_email_key | - |

### SQL（PostgreSQL）

```sql
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name VARCHAR(100) NOT NULL,
    email VARCHAR(255) NOT NULL UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    icon_url VARCHAR(500),
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP
);

COMMENT ON TABLE users IS 'システム利用者の認証・プロフィール情報を管理する';
COMMENT ON COLUMN users.id IS 'ユーザーID（主キー）';
COMMENT ON COLUMN users.name IS 'ユーザー名';
COMMENT ON COLUMN users.email IS 'メールアドレス（ユニーク）';
COMMENT ON COLUMN users.password_hash IS 'ハッシュ化されたパスワード';
COMMENT ON COLUMN users.icon_url IS 'アイコン画像のURL（任意）';
COMMENT ON COLUMN users.created_at IS '作成日時';
COMMENT ON COLUMN users.updated_at IS '更新日時';
```

### Prismaスキーマ

```prisma
model User {
  id           String   @id @default(uuid()) @db.Uuid
  name         String   @db.VarChar(100)
  email        String   @unique @db.VarChar(255)
  passwordHash String   @map("password_hash") @db.VarChar(255)
  iconUrl      String?  @map("icon_url") @db.VarChar(500)
  createdAt    DateTime @default(now()) @map("created_at") @db.Timestamp(0)
  updatedAt    DateTime? @map("updated_at") @db.Timestamp(0)

  // Relations
  teamsAsCreator    Team[]           @relation("TeamCreator")
  teamMembers       TeamMember[]
  invitations       Invitation[]
  votes             Vote[]
  smartGoals        SmartGoal[]
  notifications     Notification[]

  @@map("users")
}
```

## 2. teams（チーム）

プロジェクトチームの基本情報を管理する。

### カラム定義

| 論理名 | 物理名 | PostgreSQL型 | NULL | デフォルト値 | 補足 |
|--------|--------|--------------|------|--------------|------|
| チームID | id | UUID | NOT NULL | - | PRIMARY KEY |
| チーム名 | name | VARCHAR(50) | NOT NULL | - | - |
| 説明 | description | VARCHAR(200) | NULL | - | 任意 |
| 作成者ID | created_by_id | UUID | NOT NULL | - | FOREIGN KEY → users.id |
| 作成日時 | created_at | TIMESTAMP | NOT NULL | CURRENT_TIMESTAMP | - |
| 更新日時 | updated_at | TIMESTAMP | NULL | - | - |

### 主キー・外部キー定義

| 種別 | カラム名 | 制約名 | 参照先 | 補足 |
|------|----------|--------|--------|------|
| PRIMARY KEY | id | teams_pkey | - | - |
| FOREIGN KEY | created_by_id | teams_created_by_id_fkey | users.id | ON DELETE RESTRICT, ON UPDATE CASCADE |

### 制約定義

なし

### SQL（PostgreSQL）

```sql
CREATE TABLE teams (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name VARCHAR(50) NOT NULL,
    description VARCHAR(200),
    created_by_id UUID NOT NULL,
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP,
    CONSTRAINT teams_created_by_id_fkey FOREIGN KEY (created_by_id) REFERENCES users(id) ON DELETE RESTRICT ON UPDATE CASCADE
);

COMMENT ON TABLE teams IS 'プロジェクトチームの基本情報を管理する';
-- （COMMENT ON COLUMN 省略）
```

### Prismaスキーマ

```prisma
model Team {
  id           String    @id @default(uuid()) @db.Uuid
  name         String    @db.VarChar(50)
  description  String?   @db.VarChar(200)
  createdById  String    @map("created_by_id") @db.Uuid
  createdAt    DateTime  @default(now()) @map("created_at") @db.Timestamp(0)
  updatedAt    DateTime? @map("updated_at") @db.Timestamp(0)

  // Relations
  creator        User           @relation("TeamCreator", fields: [createdById], references: [id], onDelete: Restrict, onUpdate: Cascade)
  members        TeamMember[]
  smartGoals     SmartGoal[]
  invitations    Invitation[]

  @@map("teams")
}
```

## 3. team_members（チームメンバー）

ユーザーとチームの多対多を解決する中間テーブル。所属・ロールを管理する。

### カラム定義

| 論理名 | 物理名 | PostgreSQL型 | NULL | デフォルト値 | 補足 |
|--------|--------|--------------|------|--------------|------|
| ID | id | UUID | NOT NULL | - | PRIMARY KEY |
| チームID | team_id | UUID | NOT NULL | - | FOREIGN KEY → teams.id |
| ユーザーID | user_id | UUID | NOT NULL | - | FOREIGN KEY → users.id |
| ロール | role | VARCHAR(20) | NOT NULL | - | leader または member |
| 参加日時 | created_at | TIMESTAMP | NOT NULL | CURRENT_TIMESTAMP | - |

### 主キー・外部キー・制約

- PRIMARY KEY: id (team_members_pkey)
- FOREIGN KEY: team_id → teams.id (ON DELETE CASCADE, ON UPDATE CASCADE)
- FOREIGN KEY: user_id → users.id (ON DELETE CASCADE, ON UPDATE CASCADE)
- UNIQUE: (team_id, user_id) — team_members_team_id_user_id_key
- CHECK: role IN ('leader', 'member') — team_members_role_check

### SQL（PostgreSQL）

```sql
CREATE TABLE team_members (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    team_id UUID NOT NULL,
    user_id UUID NOT NULL,
    role VARCHAR(20) NOT NULL,
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT team_members_team_id_fkey FOREIGN KEY (team_id) REFERENCES teams(id) ON DELETE CASCADE ON UPDATE CASCADE,
    CONSTRAINT team_members_user_id_fkey FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE ON UPDATE CASCADE,
    CONSTRAINT team_members_team_id_user_id_key UNIQUE (team_id, user_id),
    CONSTRAINT team_members_role_check CHECK (role IN ('leader', 'member'))
);
```

## 4. smart_goals（SMARTゴール）

チームのSMARTゴールを管理する。

### カラム定義

| 論理名 | 物理名 | PostgreSQL型 | NULL | デフォルト値 | 補足 |
|--------|--------|--------------|------|--------------|------|
| ゴールID | id | UUID | NOT NULL | - | PRIMARY KEY |
| チームID | team_id | UUID | NOT NULL | - | FOREIGN KEY → teams.id |
| タイトル | title | VARCHAR(100) | NOT NULL | - | - |
| 具体的 | specific | TEXT | NOT NULL | - | 10〜500文字（アプリ層で制御） |
| 測定可能 | measurable | TEXT | NOT NULL | - | 最大200文字（アプリ層で制御） |
| 達成可能 | achievable | BOOLEAN | NOT NULL | - | - |
| 関連性 | relevant | TEXT | NOT NULL | - | 最大200文字（アプリ層で制御） |
| 期限 | deadline | DATE | NOT NULL | - | 未来の日付（アプリ層で制御） |
| 所有者ID | owner_id | UUID | NOT NULL | - | FOREIGN KEY → team_members.id |
| ステータス | status | VARCHAR(20) | NOT NULL | 'TODO' | TODO / IN_PROGRESS / DONE |
| 投票数 | vote_count | INTEGER | NOT NULL | 0 | 0以上 |
| 作成日時 | created_at | TIMESTAMP | NOT NULL | CURRENT_TIMESTAMP | - |
| 更新日時 | updated_at | TIMESTAMP | NULL | - | - |

### 主キー・外部キー・制約

- PRIMARY KEY: id
- FOREIGN KEY: team_id → teams.id (CASCADE/CASCADE)
- FOREIGN KEY: owner_id → team_members.id (RESTRICT/CASCADE)
- CHECK: status IN ('TODO', 'IN_PROGRESS', 'DONE')
- CHECK: vote_count >= 0

### SQL（PostgreSQL）

```sql
CREATE TABLE smart_goals (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    team_id UUID NOT NULL,
    title VARCHAR(100) NOT NULL,
    specific TEXT NOT NULL,
    measurable TEXT NOT NULL,
    achievable BOOLEAN NOT NULL,
    relevant TEXT NOT NULL,
    deadline DATE NOT NULL,
    owner_id UUID NOT NULL,
    status VARCHAR(20) NOT NULL DEFAULT 'TODO',
    vote_count INTEGER NOT NULL DEFAULT 0,
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP,
    CONSTRAINT smart_goals_team_id_fkey FOREIGN KEY (team_id) REFERENCES teams(id) ON DELETE CASCADE ON UPDATE CASCADE,
    CONSTRAINT smart_goals_owner_id_fkey FOREIGN KEY (owner_id) REFERENCES team_members(id) ON DELETE RESTRICT ON UPDATE CASCADE,
    CONSTRAINT smart_goals_status_check CHECK (status IN ('TODO', 'IN_PROGRESS', 'DONE')),
    CONSTRAINT smart_goals_vote_count_check CHECK (vote_count >= 0)
);
```

## 5. approaches（アプローチ・手順）

SMARTゴールの達成手順を管理する。最大10件はアプリ層で制御。

### カラム定義

| 論理名 | 物理名 | PostgreSQL型 | NULL | デフォルト値 | 補足 |
|--------|--------|--------------|------|--------------|------|
| アプローチID | id | UUID | NOT NULL | - | PRIMARY KEY |
| ゴールID | goal_id | UUID | NOT NULL | - | FOREIGN KEY → smart_goals.id |
| 内容 | content | VARCHAR(200) | NOT NULL | - | - |
| 完了フラグ | completed | BOOLEAN | NOT NULL | false | - |
| 順序 | sort_order | INTEGER | NOT NULL | - | - |

### SQL（PostgreSQL）

```sql
CREATE TABLE approaches (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    goal_id UUID NOT NULL,
    content VARCHAR(200) NOT NULL,
    completed BOOLEAN NOT NULL DEFAULT false,
    sort_order INTEGER NOT NULL,
    CONSTRAINT approaches_goal_id_fkey FOREIGN KEY (goal_id) REFERENCES smart_goals(id) ON DELETE CASCADE ON UPDATE CASCADE
);
```

## 6. votes（投票）

ユーザーとSMARTゴールの多対多（投票）を解決する中間テーブル。

### カラム定義

| 論理名 | 物理名 | PostgreSQL型 | NULL | デフォルト値 | 補足 |
|--------|--------|--------------|------|--------------|------|
| 投票ID | id | UUID | NOT NULL | - | PRIMARY KEY |
| ゴールID | goal_id | UUID | NOT NULL | - | FOREIGN KEY → smart_goals.id |
| ユーザーID | user_id | UUID | NOT NULL | - | FOREIGN KEY → users.id |
| 投票日時 | voted_at | TIMESTAMP | NOT NULL | CURRENT_TIMESTAMP | - |

### 制約

- UNIQUE (goal_id, user_id) — 1ユーザー1ゴール1票まで

### SQL（PostgreSQL）

```sql
CREATE TABLE votes (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    goal_id UUID NOT NULL,
    user_id UUID NOT NULL,
    voted_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT votes_goal_id_fkey FOREIGN KEY (goal_id) REFERENCES smart_goals(id) ON DELETE CASCADE ON UPDATE CASCADE,
    CONSTRAINT votes_user_id_fkey FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE ON UPDATE CASCADE,
    CONSTRAINT votes_goal_id_user_id_key UNIQUE (goal_id, user_id)
);
```

## 7. invitations（招待）

チームへの招待リンクを管理する。リーダーのみ発行可能。

### カラム定義

| 論理名 | 物理名 | PostgreSQL型 | NULL | デフォルト値 | 補足 |
|--------|--------|--------------|------|--------------|------|
| 招待ID | id | UUID | NOT NULL | - | PRIMARY KEY |
| トークン | token | VARCHAR(64) | NOT NULL | - | UNIQUE |
| チームID | team_id | UUID | NOT NULL | - | FOREIGN KEY → teams.id |
| 招待者ID | inviter_id | UUID | NOT NULL | - | FOREIGN KEY → users.id |
| 有効期限 | expires_at | TIMESTAMP | NOT NULL | - | 作成日時+7日（アプリ層で制御） |
| 使用済みフラグ | used | BOOLEAN | NOT NULL | false | - |
| 使用日時 | used_at | TIMESTAMP | NULL | - | 使用時に設定 |

### SQL（PostgreSQL）

```sql
CREATE TABLE invitations (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    token VARCHAR(64) NOT NULL UNIQUE,
    team_id UUID NOT NULL,
    inviter_id UUID NOT NULL,
    expires_at TIMESTAMP NOT NULL,
    used BOOLEAN NOT NULL DEFAULT false,
    used_at TIMESTAMP,
    CONSTRAINT invitations_team_id_fkey FOREIGN KEY (team_id) REFERENCES teams(id) ON DELETE CASCADE ON UPDATE CASCADE,
    CONSTRAINT invitations_inviter_id_fkey FOREIGN KEY (inviter_id) REFERENCES users(id) ON DELETE RESTRICT ON UPDATE CASCADE
);
```

## 8. notifications（通知）

ユーザーへのアプリ内通知を管理する。

### カラム定義

| 論理名 | 物理名 | PostgreSQL型 | NULL | デフォルト値 | 補足 |
|--------|--------|--------------|------|--------------|------|
| 通知ID | id | UUID | NOT NULL | - | PRIMARY KEY |
| ユーザーID | user_id | UUID | NOT NULL | - | FOREIGN KEY → users.id |
| 種別 | type | VARCHAR(30) | NOT NULL | - | GOAL_CREATED / STATUS_CHANGED / DEADLINE_REMINDER / GOAL_COMPLETED |
| メッセージ | message | VARCHAR(500) | NOT NULL | - | - |
| 関連ゴールID | goal_id | UUID | NULL | - | FOREIGN KEY → smart_goals.id（任意） |
| 既読フラグ | read | BOOLEAN | NOT NULL | false | - |
| 作成日時 | created_at | TIMESTAMP | NOT NULL | CURRENT_TIMESTAMP | - |

### 制約

- CHECK: type IN ('GOAL_CREATED', 'STATUS_CHANGED', 'DEADLINE_REMINDER', 'GOAL_COMPLETED')

### SQL（PostgreSQL）

```sql
CREATE TABLE notifications (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL,
    type VARCHAR(30) NOT NULL,
    message VARCHAR(500) NOT NULL,
    goal_id UUID,
    read BOOLEAN NOT NULL DEFAULT false,
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT notifications_user_id_fkey FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE ON UPDATE CASCADE,
    CONSTRAINT notifications_goal_id_fkey FOREIGN KEY (goal_id) REFERENCES smart_goals(id) ON DELETE CASCADE ON UPDATE CASCADE,
    CONSTRAINT notifications_type_check CHECK (type IN ('GOAL_CREATED', 'STATUS_CHANGED', 'DEADLINE_REMINDER', 'GOAL_COMPLETED'))
);
```

## 補足事項

### 外部キーのON DELETE/ON UPDATE動作

| テーブル | 外部キー | ON DELETE | ON UPDATE | 理由 |
|----------|----------|-----------|-----------|------|
| teams | created_by_id | RESTRICT | CASCADE | 作成者が削除されるとチームも削除できない |
| team_members | team_id, user_id | CASCADE | CASCADE | チーム/ユーザー削除時はメンバー情報も削除 |
| smart_goals | team_id | CASCADE | CASCADE | チーム削除時はゴールも削除 |
| smart_goals | owner_id | RESTRICT | CASCADE | 所有者が削除されるとゴールも削除できない |
| approaches | goal_id | CASCADE | CASCADE | ゴール削除時はアプローチも削除 |
| votes | goal_id, user_id | CASCADE | CASCADE | ゴール/ユーザー削除時は投票も削除 |
| invitations | team_id | CASCADE | CASCADE | チーム削除時は招待も削除 |
| invitations | inviter_id | RESTRICT | CASCADE | 招待者が削除されると招待も削除できない |
| notifications | user_id, goal_id | CASCADE | CASCADE | ユーザー/ゴール削除時は通知も削除 |

### アプリ層で制御する項目

- `smart_goals.specific`: 10〜500文字のバリデーション
- `smart_goals.measurable`, `relevant`: 最大200文字のバリデーション
- `smart_goals.deadline`: 未来の日付のバリデーション
- `approaches`: 最大10件の制限
- `invitations.expires_at`: 作成日時+7日の計算
