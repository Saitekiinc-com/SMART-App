# 02_各画面の構成要素・コンポーネント

## 目的

各画面のレイアウト・エリア・コンポーネント構成を記載する。

## 画面ごとの構成要素・コンポーネント

| 画面ID | エリア | コンポーネント名 | 説明 |
|--------|--------|------------------|------|
| S-01 | メイン | AuthForm（認証フォーム） | メール、パスワード、Googleログインボタン |
| S-01 | メイン | FormElements | テキスト入力、ボタン |
| S-02 | メイン | InviteAcceptCard | チーム名、招待者情報、参加ボタン |
| S-02 | オーバーレイ | ConfirmDialog | ログイン済み時の参加確認 |
| S-03 | メイン | TeamSelectList | 所属チーム一覧、選択でダッシュボードへ |
| S-04 | ヘッダー | AppHeader | チーム名、通知アイコン、ユーザーアイコン、チーム切替、設定（リーダーのみ） |
| S-04 | サマリー | DashboardSummary | 進行中ゴール数、達成率 |
| S-04 | メイン | GoalCard（ゴール一覧） | タイトル、ステータス色分け、投票数バッジ、アプローチ進捗 |
| S-04 | メイン | FilterSortUI | ステータス別・投票数順のフィルタ・ソート |
| S-04 | メイン | EmptyState | ゴール0件時の表示 |
| S-04 | FAB | FAB | 新規ゴール作成ボタン |
| S-05 | メイン | WizardFrame | 6ステップのステップインジケーター、コンテンツ領域、戻る/次へ/キャンセル |
| S-05 | 各ステップ | FormElements | テキスト入力、日付選択、チェックボックス、アプローチリスト |
| S-05 | オーバーレイ | ConfirmDialog | キャンセル時の入力破棄確認 |
| S-06 | ヘッダー | AppHeader | 共通ヘッダー |
| S-06 | メイン | GoalDetailPanel | タイトル、SMART要素、投票セクション、アプローチチェックリスト、ステータス変更、編集/削除ボタン |
| S-06 | メイン | VoteUI | 投票ボタン、投票数表示 |
| S-06 | メイン | StatusBadge | ステータス表示 |
| S-06 | オーバーレイ | ConfirmDialog | 削除確認 |
| S-07 | ヘッダー | AppHeader | 共通ヘッダー |
| S-07 | メイン | WizardFrame | ゴール編集用ステップUI |
| S-07 | メイン | FormElements | 各入力項目 |
| S-07 | オーバーレイ | ConfirmDialog | キャンセル確認 |
| S-08 | オーバーレイ | NotificationListModal | 通知リスト、未読/既読、閉じるボタン |
| S-09 | ヘッダー | AppHeader | 共通ヘッダー（リーダーのみ表示） |
| S-09 | メイン | TeamSettingsContent | チーム情報編集フォーム、メンバー一覧、招待ボタン |
| S-10 | オーバーレイ | InviteLinkModal | 招待URL表示、コピーボタン、有効期限表示 |
