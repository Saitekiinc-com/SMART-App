# 02_各画面の構成要素・コンポーネント

## 目的

各画面のレイアウト・エリア・コンポーネント構成を記載する。

## 記載形式（テンプレート）

| 画面ID | エリア | コンポーネント名 | 説明 |
|--------|--------|------------------|------|
| （例）S-04 | ヘッダー | Header | チーム名、通知アイコン、ユーザーアイコン |
| （例）S-04 | サマリー | SummaryCard | 進行中ゴール数、達成率 |
| （例）S-04 | ゴール一覧 | GoalList | ゴールカード一覧 |
| （例）S-04 | FAB | FabButton | 新規ゴール作成ボタン |

## S-04: チームダッシュボード

| 画面ID | エリア | コンポーネント名 | 説明 |
|--------|--------|------------------|------|
| S-04 | ヘッダー | AppHeader | チーム名、通知アイコン、ユーザーアイコン、チーム切替、設定アイコン（リーダーのみ） |

| S-04 | ゴール一覧 | VoteUI | 投票ボタン・投票数表示 |
| S-04 | フローティング | FAB | 新規ゴール作成ボタン（右下固定） |
| S-04 | 空状態 | EmptyState | ゴールが0件の場合の表示（イラスト、説明、アクションボタン） |
| S-04 | ローディング | LoadingState | データ取得中のスケルトンスクリーン |

| 画面ID | エリア | コンポーネント名 | 説明 |
