# 01_画面一覧と画面ID

## 目的

画面ID（S-01〜S-10）と画面名・機能ID・概要を一覧化する。

## 一覧（テンプレート）

| 画面ID | 画面名 | 機能ID | 概要 | 備考 |
|--------|--------|--------|------|------|
| S-01 | ログイン / サインアップ | F-001 | メール/パスワード、Googleログイン | - |
| S-02 | 招待受諾画面 | F-003 | 招待リンク経由のチーム参加 | - |
| S-03 | チーム選択 | F-004 | 複数チーム所属時の切替 | - |
| S-04 | チームダッシュボード | F-006, F-011, F-012 | ゴール一覧、サマリー、FAB | - |
| S-05 | SMARTゴール作成ウィザード | F-005 | 6ステップのゴール入力フォーム | - |
| S-06 | ゴール詳細 | F-007, F-010, F-011 | 詳細表示、投票、アプローチ、ステータス | - |
| S-07 | ゴール編集画面 | F-008 | 既存ゴールの編集 | - |
| S-08 | 通知一覧モーダル | F-013, F-014 | 通知の確認・既読管理 | - |
| S-09 | チーム設定画面 | F-002, F-003, F-015 | チーム情報編集、メンバー管理（リーダーのみ） | - |
| S-10 | 招待リンク生成モーダル | F-003 | 招待URL発行・コピー（リーダーのみ） | - |
