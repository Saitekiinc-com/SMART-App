# 07_コンポーネント設計

## 目的

各画面で利用するコンポーネントの一覧・階層・仕様およびディレクトリ構成を定義する。02_各画面の構成要素・コンポーネントを主なインプットとし、08_純粋関数の設計・09_カスタムフック設計で参照する。

## 2. コンポーネント階層（ツリー）

02_各画面の構成要素・コンポーネントに沿い、画面（ページ）をルートとした階層を示す。

### S-01: ログイン/サインアップ

```plain text
PageLoginSignup
└── AuthForm
    ├── FormElements（メール入力）
    ├── FormElements（パスワード入力）
    ├── FormElements（名前入力・サインアップ時）
    ├── FormElements（パスワード確認・サインアップ時）
    ├── FormElements（エラー表示）
    ├── FormElements（ログイン/サインアップボタン）
    ├── FormElements（Googleログインボタン）
    └── リンク（ログイン/サインアップ切り替え）
```

### S-04: チームダッシュボード

```plain text
PageDashboard
├── AppHeader
├── DashboardSummary
├── FilterSortUI
├── GoalList
│   ├── GoalCard（複数）
│   │   ├── StatusBadge
│   │   └── VoteUI
│   ├── EmptyState（0件時）
│   └── LoadingState（取得中）
├── FAB
└── （S-08 表示時）NotificationListModal
```

### S-05: SMARTゴール作成ウィザード

```plain text
PageGoalCreate
├── AppHeader（戻る・ステップインジケーター）
├── WizardFrame
│   ├── FormElements（各ステップの入力・Step1〜6）
│   └── FormElements（エラー表示）
├── FormElements（戻る/次へ/キャンセル/保存）
└── ConfirmDialog（キャンセル確認）
```

### S-06: ゴール詳細

```plain text
PageGoalDetail
├── AppHeader
├── GoalDetailPanel
│   ├── タイトル表示
│   ├── StatusDisplay
│   ├── VoteUI
│   ├── SMART要素表示
│   ├── アプローチチェックリスト
│   ├── FormElements（編集/削除/フィードバック）
│   └── ConfirmDialog（削除確認）
└── LoadingState（取得中）
```

（S-02, S-03, S-07, S-08, S-09, S-10 の階層は 02_各画面の構成要素・コンポーネント に準拠。）

## 3. コンポーネント仕様（主要なもの）

| コンポーネント名 | props | 主な state | 備考（API等） |
|------------------|-------|------------|---------------|
| AppHeader | title?, showBack?, showTeamSwitch?, showSettings?, stepIndicator?, onBack? | 最小限 | 06_呼び出すAPI の認証コンテキストを利用 |
| GoalList | teamId（必須） | goals[], isLoading, filterStatus, sortBy | GET /api/teams/{teamId}/goals |
| GoalCard | goal, onClick, onVote? | hasVoted | POST/DELETE /api/goals/{goalId}/votes |
| VoteUI | goalId, voteCount, hasVoted, disabled?, onVoteChange | ローカル更新 | POST/DELETE votes |
| WizardFrame | steps, currentStep, onStepChange, initialValues? | formValues, errors | S-05: POST /api/goals、S-07: GET/PUT /api/goals/{id} |
| GoalDetailPanel | goalId | goal, isLoading | GET /api/goals/{goalId}。編集/削除は権限時のみ |
| StatusDisplay | status, goalId, onStatusChange | 楽観的更新 | PATCH /api/goals/{goalId}（body: status） |
| NotificationListModal | isOpen, onClose | notifications[], isLoading | GET /api/notifications、PATCH 既読 |
| InviteLinkModal | isOpen, teamId（必須）, onClose | inviteUrl, expiresAt, isLoading | POST/GET /api/teams/{teamId}/invites |
| ConfirmDialog | isOpen, title, message, confirmLabel?, cancelLabel?, onConfirm, onCancel, variant? | - | 削除時は variant=danger |
| ToastNotification | message, type（success/error/info） | - | 05_フロント側処理フロー「トースト通知」 |

## 4. ディレクトリ・ファイル構成方針

- **Next.js App Router** を想定。
- **ページ**: app/ 配下にルート・動的セグメントで配置（例: app/(auth)/login/page.tsx（S-01）、app/(app)/dashboard/[teamId]/page.tsx（S-04）、app/(app)/goals/[goalId]/page.tsx（S-06）、app/(app)/goals/[goalId]/edit/page.tsx（S-07）、app/(app)/settings/[teamId]/page.tsx（S-09）、app/invite/[token]/page.tsx（S-02））。
- **共通コンポーネント**: components/ui/（Button, Input, Select, StatusBadge, VoteUI, ConfirmDialog, Toast, LoadingState, EmptyState, FAB, AppHeader）。
- **画面固有**: components/ 配下で機能ごとに分割（auth/AuthForm, dashboard/GoalList・GoalCard, goal/WizardFrame・GoalDetailPanel, team/TeamSelectList・TeamSettingsContent, notifications/NotificationListModal, invite/InviteLinkModal）。
- **命名**: コンポーネントファイルは PascalCase（GoalCard.tsx）。ディレクトリは小文字または kebab-case。
- **レイアウト**: app/(app)/layout.tsx でヘッダー・認証ガード。モーダル（S-08, S-10）は state で表示制御。
