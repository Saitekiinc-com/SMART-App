# 09_カスタムフック設計

## 目的

API 呼び出し・認証状態・フォーム送信・一覧の取得・更新・削除など、コンポーネントから切り出した「副作用と state のまとまり」であるカスタムフックの一覧・責務・入出力を定義する。07_コンポーネント設計・08_純粋関数の設計 と整合した実装を可能にし、06_呼び出すAPI で定義された API をフック経由で呼び出す責務を明確にする。

---

## 1. カスタムフック一覧

| フック名 | 責務 | 主に呼び出すAPI（パス/メソッド） | 主な利用先 | 備考 |
|----------|------|----------------------------------|------------|------|
| useAuth | ログイン・サインアップ・現在ユーザー取得・認証状態 | POST /api/auth/login, POST /api/auth/signup, GET /api/users/me | AuthForm（S-01）、認証ガード | 08: validateEmail, validatePassword 等。トークン保存・遷移はフック内 |
| useInvite | 招待情報取得（token 指定） | GET /api/invites/{token} | InviteAcceptCard（S-02） | token は URL パラメータ |
| useAcceptInvite | 招待受諾（チーム参加） | POST /api/invites/{token}/accept | PageInviteAccept（S-02） | 未ログイン時は認証後に参加 |
| useTeams | 所属チーム一覧取得 | GET /api/teams | TeamSelectList（S-03） | 認証必須 |
| useGoals | ゴール一覧取得（フィルター・並び替え対応） | GET /api/teams/{teamId}/goals | GoalList（S-04） | クエリ: status, sort。mutate で再取得 |
| useVote | 投票・投票解除（トグル） | POST/DELETE /api/goals/{goalId}/votes | VoteUI（S-04, S-06） | 未着手のみ投票可能。voteCount / hasVoted を返す |
| useCreateGoal | ゴール作成 | POST /api/goals | WizardFrame（S-05） | 08: validateGoalForm, buildGoalCreateBody。成功時は S-04 へ遷移 |
| useGoal | ゴール詳細取得 | GET /api/goals/{goalId} | GoalDetailPanel（S-06）、WizardFrame 編集時（S-07） | 認証必須 |
| useUpdateGoal | ゴール更新 | PUT /api/goals/{goalId} | WizardFrame（S-07） | 08: validateGoalForm, buildGoalUpdateBody |
| useDeleteGoal | ゴール削除 | DELETE /api/goals/{goalId} | GoalDetailPanel（S-06） | 確認ダイアログはコンポーネント側。成功時 S-04 へ遷移 |
| useGoalStatus | ゴールステータス更新 | PATCH /api/goals/{goalId}（body: status） | StatusDisplay（S-06） | 楽観的更新可 |
| useApproachComplete | アプローチ完了状態更新 | PATCH /api/approaches/{approachId}（body: completed） | アプローチチェックリスト（S-06） | 進捗%はレスポンスで更新 |
| useGoalFeedback | ゴール完了時フィードバック保存 | POST /api/goals/{goalId}/feedback | GoalDetailPanel（S-06） | ステータス DONE 時 |
| useNotifications | 通知一覧取得・既読化 | GET /api/notifications, PATCH /api/notifications/{id} | NotificationListModal（S-08） | unread_only クエリ可 |
| useTeam | チーム情報取得 | GET /api/teams/{teamId} | TeamSettingsContent（S-09） | 認証必須 |
| useUpdateTeam | チーム情報更新 | PUT /api/teams/{teamId} | TeamSettingsContent（S-09） | 08: validateTeamForm, buildTeamUpdateBody。トーストで成功/失敗 |
| useTeamMembers | メンバー一覧取得 | GET /api/teams/{teamId}/members | TeamSettingsContent（S-09） | リーダー/メンバー表示 |
| useRemoveMember | メンバー削除 | DELETE /api/teams/{teamId}/members/{userId} | TeamSettingsContent（S-09） | リーダーのみ。確認はコンポーネント側 |
| useUpdateMemberRole | メンバーロール変更 | PATCH /api/teams/{teamId}/members/{userId}（body: role） | TeamSettingsContent（S-09） | リーダーのみ |
| useInviteLink | 招待リンク生成・既存取得 | POST/GET /api/teams/{teamId}/invites | InviteLinkModal（S-10） | リーダーのみ。url, expiresAt を返す |

## 2. フック仕様（主要なもの）

- **useAuth**: 引数なし。戻り値 user, isAuthenticated, isLoading, login(values), signup(values), logout, refetch。送信前に 08 の validateEmail, validatePassword, validatePasswordMatch, validateName を実行。エラー時は 05 に準拠してトーストまたはエラー表示。
- **useGoals(teamId, options?)**: teamId 必須、options で status, sort。戻り値 goals, isLoading, error, mutate。
- **useCreateGoal**: 戻り値 submit(values), isLoading, error。送信前に validateGoalForm、通過時 buildGoalCreateBody で POST /api/goals。成功時トースト「ゴールを作成しました」＋ S-04 へ遷移。
- **useUpdateGoal(goalId)**: 戻り値 update(values), isLoading, error。validateGoalForm, buildGoalUpdateBody で PUT。成功時「ゴールを更新しました」＋ S-06 へ遷移。
- **useGoal(goalId)**: 戻り値 goal, isLoading, error, mutate。
- **useDeleteGoal(goalId)**: 戻り値 deleteGoal(), isLoading, error。確認は呼び出し側。成功時「ゴールを削除しました」＋ S-04 へ遷移。
- **useVote(goalId)**: 戻り値 voteCount, hasVoted, toggleVote(), isLoading。ステータス TODO かつ未投票時のみ API 呼び出し。エラー時トースト、画面遷移なし。
- **useUpdateTeam(teamId)**: 戻り値 update(values), isLoading, error。validateTeamForm, buildTeamUpdateBody。成功時「チーム情報を更新しました」＋画面内更新。
- **useNotifications(options?)**: 戻り値 notifications, isLoading, markAsRead(id), mutate。
- **useInviteLink(teamId)**: 戻り値 inviteUrl, expiresAt, isLoading, createInvite(), fetchExisting()。エラー時トースト「招待リンクの生成に失敗しました」等。

## 3. ディレクトリ・ファイル構成方針

- 07_コンポーネント設計・08_純粋関数の設計 と整合。プロジェクトルートに **hooks/** を置く想定（app/(app)/_hooks/ でも可）。
- **配置例**: hooks/useAuth.ts（useAuth）、hooks/useInvite.ts（useInvite, useAcceptInvite）、hooks/useTeams.ts（useTeams）、hooks/useGoals.ts（useGoals, useGoal, useCreateGoal, useUpdateGoal, useDeleteGoal, useGoalStatus, useGoalFeedback, useVote）、hooks/useApproach.ts（useApproachComplete）、hooks/useNotifications.ts（useNotifications）、hooks/useTeam.ts（useTeam, useUpdateTeam, useTeamMembers, useRemoveMember, useUpdateMemberRole）、hooks/useInviteLink.ts（useInviteLink）。
- **命名**: ファイル名 useXxx.ts。フック名は use で始まる camelCase。mutate / refetch は 05 で「再取得」と記載のタイミングで呼び出す。
- **認証**: useAuth のトークン保存・Bearer 付与は共通化（axios インターセプター等）。GET /api/users/me はログイン/サインアップ成功直後とアプリ起動時の認証チェックで利用。
